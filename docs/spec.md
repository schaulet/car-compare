# Spécification fonctionnelle - car-compare

## Vue d'ensemble

car-compare est un outil permettant de comparer différentes options d'achat ou de location de véhicules.

## Fonctionnalités prévues

### F1 - Comparaison de véhicules
- Permettre la saisie des caractéristiques de plusieurs véhicules
- Afficher un comparatif côte à côte

### F2 - Calcul des coûts
- Calculer le coût total de possession (achat)
- Calculer le coût total de location (LLD/LOA)
- Comparer les deux options

### F3 - Aide à la décision
- Proposer des critères de choix personnalisables
- Générer une recommandation basée sur le profil utilisateur

## Critères de comparaison

- Prix d'achat / loyer mensuel
- Consommation / coût carburant
- Assurance
- Entretien
- Décote / valeur résiduelle
